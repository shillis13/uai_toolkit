## Usage Notes

- One ADR per decision. Don't bundle.
- Never edit an accepted ADR — write a new one that supersedes it.
- "Context" is the most important section — a reader who understands the context can evaluate the decision independently.
- Keep it short. If an ADR is more than one page, it's covering too much.
