description: In documents, define acronyms/coined terms before first use; add a Terms

status: active
---

In any document, expand every acronym on its first use and give a one-line definition for any coined term or term-of-art. If a document introduces several, add a short **Terms** section near the top.

**Why:** Readers — other sessions, future-me, PianoMan — don't share the author's context. A term used before it's defined is a defect; it forces the reader to guess or go hunt. Surfaced 2026-06-15 when the awareness-feed spec (todo_0313) used FeedIndex / auto-floor / YAGNI / UPS / OBE / BOF without upfront definitions and PianoMan had to stop and ask.

**How to apply:** When authoring any document (specs, design docs, READMEs, notes), define-before-use. Codified in global Universal Rules (`~/.claude/CLAUDE.md`). Related: [[feedback_include_file_paths]].
