name: feedback_include_file_paths
description: Always include full file path when referencing any document or file
status: active
---

Any document or file reference in responses must include the full file path.

**Why:** User has a standing request that document references always include the file URL/path so they can navigate directly.

**How to apply:** When mentioning any file (architecture docs, design docs, scripts, configs, etc.), always include the absolute path. Don't just say "the architecture overview" — say "the architecture overview at `/path/to/file.md`".
