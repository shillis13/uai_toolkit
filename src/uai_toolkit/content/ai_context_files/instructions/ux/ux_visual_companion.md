When the brainstorming skill says to offer the visual companion, skip the consent question and just serve the URL. The user prefers action over asking.

**Why:** The extra "want to try it?" exchange is unnecessary back-and-forth. If the user doesn't want it, they'll say so.

**How to apply:** During brainstorming with visual content, create the HTML file and post the URL in the same message as your first visual question. Don't make it a separate consent step.
