PianoMan repeatedly wants disclosure chevrons BIGGER than the default. Banked sizes that landed (2026-06-29):
- **Section/collapse chevrons** (e.g. Project Editor Docs/Files/Team headers): **~30–32px** font-size — "3-4× the label." 22px read as too small; 32px is the keeper.
- **Tree / inline-row carets** (Work Mgr tree expand/collapse): **~17px** (up from a default ~10px).

**Why:** he finds default chevrons too small to see/click. **How to apply:** when adding a collapsible section, start the chevron at ~30px (section) or ~17px (inline tree), not the default. He said "start to remember what sizes work" — so default to these, don't undershoot. Related: [[feedback_overshoot_visual_adjustments]], [[feedback_more_colors_means_bold_backgrounds]].
