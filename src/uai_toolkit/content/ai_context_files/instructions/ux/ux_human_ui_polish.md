  optional

User cares about human player UI polish — button layout stability, color consistency, grouping. These aren't optional nits, they're part of what makes the game feel right to play.

**Why:** "Thank you for tolerating my nits that don't matter to AI players" — the user sees these as important even if they're cosmetic. The game needs to be enjoyable for humans too.

**How to apply:** When building UI, proactively apply faction colors to faction-specific elements. Keep layouts stable (no shifting on click). Group related controls logically. Don't dismiss visual polish as low priority.
