# CLI Lifecycle Management

Launch, monitor, and cleanup CLI instances.

## Scripts

- **launch_claude_cli_task.scpt** - Launch CLI task via AppleScript
- **launch_codex_cli_task.scpt** - Launch Codex task via AppleScript
- **cleanup_cli_sessions.sh** - Clean up old/stale sessions
- **list_cli_sessions.sh** - List active CLI sessions
