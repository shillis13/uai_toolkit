My three assumptions (the forks I want your read on)
1 Navigator expands uniformly. Every aspect (not just Work) expands in the left nav into its primary items — Work→todos, Team→AIs, Comms→channels. Clicking an item loads its detail; clicking the aspect header loads the aspect landing. Consistent & powerful — but it's a choice vs. "only Work expands."
2 Doc Folder == Work Folder == one mechanism. A single generic project-scoped folder tree (multi-select, move, open, archive-not-delete), instantiated twice — once for Docs in Overview, once for work-files under a todo. One component, two mounts.
3 Right Panel == the Session tab's ContextPanel, reused. Same component, content switches on what's selected in the Detail area: a file → file metadata; an AI → the very same session detail a Session tab shows.
